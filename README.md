# Fleur de Mode - Интернет-магазин модной одежды

Fleur de Mode — это веб-сайт интернет-магазина модной одежды. На сайте представлены разделы для покупок, информации о компании, а также возможность стать партнером. Главная страница включает слайдер с акциями, раздел с популярными товарами и секцию с промокодом для новых клиентов.

## Структура проекта

- aboutus/ — содержит информацию о магазине, включая карту с его расположением.
- beapartner/ — раздел с формой для подачи заявки на партнёрство.
- cart/ — корзина для добавления и удаления товаров.
- main/ — главная страница проекта.
- main_images/ — изображения, используемые на главной странице.
- shop/ — каталог товаров, содержащий слайдер.
- shop_images/ — изображения товаров.
- aboutus.html — HTML-файл страницы "О нас".
- beapartner.html — HTML-файл страницы "Стать партнёром".
- cart.html — HTML-файл страницы корзины.
- main.html — HTML-файл главной страницы.
- shop.html — HTML-файл магазина.

## Функциональность

- Главная страница — отображает основную информацию о магазине.
- Магазин — содержит товары и слайдер для их удобного просмотра.
- Корзина — позволяет добавлять и удалять товары.
- Форма партнёрства — даёт возможность отправить заявку.
- Страница "О нас" — отображает карту расположения магазина.

## Технологии

Проект использует HTML, CSS и JavaScript для отображения страниц и обеспечения их функциональности.
