# Даст Код - доедешь

Простое веб-приложение для поиска маршрутов между двумя точками с использованием API Яндекс.Расписаний и Яндекс Геокодера. Приложение позволяет указать начальную и конечную точки, дату поездки и выбрать сортировку по времени или стоимости. Результаты отображаются с учетом пересадок, типов транспорта и расчетной стоимости поездки.

## Особенности

- Составление комбинированых маршрутов
- Поиск маршрутов между двумя адресами с использованием Яндекс.Расписаний.
- Геокодирование адресов через Яндекс Геокодер для получения координат.
- Расчет стоимости поездки на основе длительности и типа транспорта.
- Фильтрация маршрутов по времени или цене.
- Поддержка кэширования данных через Memcached (на стороне сервера).
- Отображение информации о копирайте от Яндекс.Расписаний.
- Адаптивный дизайн для мобильных устройств.

## Требования

Приложение уже размещено на хостинге и готово к использованию. Вам понадобится только:
- Современный веб-браузер (Chrome, Firefox, Safari и т.д.).
- Доступ к интернету.

Серверная часть настроена на хостинге (`http://yashak24.beget.tech/`), включая PHP, Memcached и необходимые API-ключи.

## Использование

1. Перейдите по адресу: `http://yashak24.beget.tech/`.
2. Заполните форму:
   - **Откуда**: Введите начальный адрес (например, "Москва, Красная площадь").
   - **Куда**: Введите конечный адрес (например, "Санкт-Петербург, Невский проспект").
   - **Когда**: Выберите дату поездки.
   - **Фильтр**: Выберите сортировку по времени или стоимости.
3. Нажмите кнопку **Поехали** для поиска маршрутов.
4. Просмотрите результаты:
   - Информация о маршрутах, включая время отправления/прибытия, тип транспорта, пересадки и расчетную стоимость.
   - Копирайт от Яндекс.Расписаний внизу страницы.
5. Если результаты отображаются некорректно, попробуйте перезагрузить страницу, используя сочетание клавиш Ctrl+F5.

## Структура проекта

- **Chemp.php**: Основной файл, содержащий backend (PHP).
- **index.html**: Файл с HTML разметкой сайта.
- **style.css**: Стили для интерфейса приложения.
- **script.js**: Клиентская логика для обработки формы и отображения результатов.
- **debug.txt**: Файл для логирования ошибок (на сервере).

## Backend

Класс `YandexRaspAPI` реализует взаимодействие с API Яндекс.Расписаний и Яндекс Геокодера:
- `getCoordinatesByAddress($address)`: Получает координаты по адресу.
- `getNearestSettlement($lat, $lng, $distance)`: Находит ближайший населенный пункт.
- `getRoutes($from, $to, $params)`: Ищет маршруты между пунктами.
- `getCopyright()`: Возвращает информацию о копирайте.
- `makeRequest($url, $timeout)`: Выполняет HTTP-запрос с помощью cURL.

Кэширование реализовано через Memcached на сервере для ускорения запросов.

## Frontend

- Форма ввода данных с полями "Откуда", "Куда", "Когда" и фильтром.
- Кнопка "↔" для быстрой смены мест "Откуда" и "Куда".
- Динамическое отображение маршрутов с деталями (время, пересадки, стоимость).
- Адаптивный дизайн с использованием CSS медиа-запросов.
